# 🌱 INDDA UNALM · Sistema de Gestión Agroindustrial

|---|---|

## 📊 Módulos del dashboard

| Pestaña | Contenido |
|---|---|
| Resumen General | KPIs reales · filtros múltiples · conclusiones automáticas |
| Producción | Gráfico mensual apilado · ranking por producto |
| Calidad | % defectuoso · tipos de defecto · análisis por turno |
| Atípicos | Método IQR · boxplot · scatter · tabla de lotes atípicos |
| Inventario | Stock vs mínimo · cobertura por insumo |
| Responsables | Ranking de desempeño · gráfico doble eje |
| Datos en vivo | Ingreso y eliminación de lotes · detección automática de atípicos |

## 🗃️ Base de datos

Simulada en R con 300 lotes, 2,000 inspecciones de calidad, 15 insumos y 5 responsables. Variables estadísticamente coherentes y alineadas con ISO 9001:2015 e ISO 22000:2018.

## 🛠️ Tecnologías

`HTML5` · `CSS3` · `JavaScript ES6+` · `Chart.js 4.4` · `R` · `Power BI` · `GitHub Pages`
